# Shopping Cart

This is a simple shopping cart that allows users to:

- Increase and decrease item quantities.
- Calculate and update the total price dynamically.
- Like/unlike items by clicking a heart icon.
- Remove items from the cart using a trash icon.

## Features

- **Increment & Decrement Quantity**: Users can add or remove items while updating the total price.
- **Like Items**: Clicking the heart icon toggles the like status (red for liked, black for unliked).
- **Remove Items**: Clicking the trash icon hides the item from the cart.

## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/shopping-cart.git
   ```
2. Open `index.html` in a browser.

## Usage

- Click the `+` button to increase item quantity.
- Click the `-` button to decrease item quantity (minimum of 1).
- Click the heart icon to like/unlike an item.
- Click the trash icon to remove an item from the cart.
